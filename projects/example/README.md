# Example project

This copyright-free sample contains two tiny FFmpeg-generated videos:

1. a landscape clip with a generated test pattern and tone;
2. a portrait clip without audio.

It intentionally exercises resolution/orientation normalization and missing-audio handling. Metadata, frames, scene boundaries, and available local analysis are already cached. Open **Creator Launch — Example** and click **Generate edit** to render a real version immediately, or choose **Re-analyze** after configuring Whisper, OCR, or a vision model.
